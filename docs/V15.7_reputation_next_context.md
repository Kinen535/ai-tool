## 二、V15.7 开发原则

1. 不推翻 V15.6 架构
2. 优先增强业务判断，不再先做安全底座
3. 所有新增页面必须进入 full check
4. 所有输出避免暴露路径、token、维护路由
5. 中文显示优先，英文枚举只保留在后端和表单 value 中
6. AI 只做解释和总结，不直接替代人工决策

## 三、V15.7 优先开发方向

A1：主体详情页增加处置建议

目标：
- 根据主体风险等级、信任等级、事件数量、高影响事件数量，自动显示处置建议。
- 黑名单：建议重点标记，避免重新吸纳
- 高危：建议人工复核并补充证据
- 预警：建议观察，不直接处置
- 正常：暂无处置建议

A2：事件详情页增加影响评估

目标：
- 根据事件影响等级、关联主体数量、高风险主体数量，自动生成影响评估。
- 严重事件加高危主体：建议列入重点风险事件
- 普通事件加已关联主体：作为历史记录保留

A3：检索页增加风险结论卡

目标：
- 搜索游戏编号或名称后，顶部直接显示风险结论。
- 已命中黑名单主体
- 已有关联严重事件
- 证据链完整
- 建议谨慎处理

A4：高风险主体人工复核状态

目标：
- 给主体增加人工复核状态：
  - 未复核
  - 已确认
  - 误报
  - 暂缓
- 先做页面显示与编辑，不急着做复杂流程。

A5：信誉档案库 AI 总结预留

目标：
- 规则引擎先生成事实
- AI 只负责解释成自然语言
- 不让 AI 直接决定黑名单或清理名单

## 四、当前建议下一步

建议从 V15.7-A1 开始：

主体详情页增加处置建议。

原因：
- 主体详情页是最容易形成管理价值的位置
- 不影响现有数据结构
- 可以先规则生成，不依赖大模型
- 方便后续接入检索页风险结论卡
